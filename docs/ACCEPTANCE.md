# Проверка локального комплекта

`.venv/bin/python scripts/verify_local_install.py` копирует только отслеживаемые Git файлы в отдельный временный каталог, создаёт новое виртуальное окружение и устанавливает requirements.txt. Для установки нужны доступные пакеты или локальный кеш pip. Личные базы, .env и прежнее окружение не копируются.

Скрипт применяет миграции к пустой SQLite, проверяет их согласованность, запускает весь набор тестов, создаёт вымышленный демоаккаунт, проверяет страницы кабинета и финансовый PDF. Затем запускает настоящий сервер из другого рабочего каталога, проверяет главную/CSS по HTTP и завершает собственный процесс. Временный каталог удаляется. Отчёт reports/local-install-v1.json содержит SHA исходников и версии зависимостей.

23 ноября 2026 проверка пройдена. Это воспроизведение локальной установки и сценариев; визуальная проверка браузером остаётся открытой. SQLite не подтверждает блокировки PostgreSQL: отдельное реальное испытание двух соединений описано в POSTGRESQL.md. Демонстрационные финансовые данные вымышлены.

# Локальный PostgreSQL

Укажите `DATABASE_URL` в окружении запуска, например `postgresql://USER@127.0.0.1:5432/finance`, затем выполните `python main.py migrate`. Реальный пароль хранится вне репозитория. В URL сохраняются sslmode, channel_binding и connect_timeout; повторяющиеся, неизвестные и некорректные параметры отклоняются. При отсутствии переменной локальный запуск использует SQLite.

22 ноября 2026 года миграции и все 59 тестов прошли на отдельном локальном PostgreSQL 16.14. Два параллельных соединения провели одну плановую оплату: получилась ровно одна денежная операция и одно событие проведения. В SQLite этот тест блокировок пропускается: SQLite не доказывает поведение SELECT FOR UPDATE.

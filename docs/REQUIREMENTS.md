# Требования проекта №1

Тема: «Разработка веб-приложения визуальной аналитики для управления денежными потоками коммерческого предприятия».
Автор: Жукова Кристина Дмитриевна. Аккаунт: `kristinka58205`.

Источник: индивидуальное задание от 2 ноября 2026 года, направление 38.03.05 Бизнес-информатика, профиль «Цифровая экономика»; раздел требований к сетевому ресурсу, пункты 1–21. Срок практики: 9 ноября — 6 декабря 2026 года.

## Обязательные условия

- Собственный веб-сервис на PHP, JavaScript либо Python с Django/Flask; без CMS и готовых плагинов вместо разработки.
- 50+ содержательных коммитов с итеративным развитием в период практики и подготовки ВКР.
- 2000+ логических строк кода, включая разметку, без пустых строк и комментариев.
- 10+ публичных страниц, 10+ пунктов навигации, хлебные крошки, адаптивность.
- SQL-база с 10+ таблицами, её структура и данные для воспроизведения в репозитории.
- Минимум три роли, пять административных страниц и пять страниц личного кабинета.
- Обратная связь, работа с файлами, формирование документов, ФИО автора в подвале.
- Анализ AS IS / TO BE, ТЗ, архитектура, модель данных и описание прав в отчёте.

## Рабочая декомпозиция предметной области

Организации, счета, контрагенты, статьи денежных потоков, операции, бюджеты, проекты, плановые платежи, импорт и выгрузки. Предполагаемые роли: финансовый специалист, руководитель и администратор. Состав уточняется при начале реализации.

Основной сценарий: загрузить или ввести операции → проверить суммы и даты → разнести по статьям → получить притоки, оттоки и остатки → сравнить план с фактом → сформировать отчёт. Источник демонстрационных данных и организация ещё не выбраны.

Статус: реализация начата; используется Django, подключаются авторизация и собственные предметные модели. Открытые функции и проверки перечислены в PROGRESS.md; комплект устанавливается и запускается локально.

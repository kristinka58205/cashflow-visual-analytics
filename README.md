# Поток — визуальная аналитика денежных потоков

Тема: «Разработка веб-приложения визуальной аналитики для управления денежными потоками коммерческого предприятия».
Автор: Жукова Кристина Дмитриевна (`kristinka58205`).

Счета, статьи, контрагенты и проекты; поступления и расходы; месячные бюджеты и плановые платежи; CSV-импорт с проверкой и выгрузки; аналитика по периодам и PDF-отчёт. Суммы рассчитываются через Decimal. Личные записи и организации разделены, права администратора, финансового специалиста и руководителя проверяются на сервере. Документы операций скачиваются только участниками соответствующей рабочей области. Есть журнал действий, публичное руководство, обратная связь и административный кабинет.

## Запуск

Python 3.12 или новее:

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python run_local.py
```

Откройте http://127.0.0.1:8021 и зарегистрируйте личный аккаунт. Миграции применяются автоматически. Для запуска из IDE выберите интерпретатор `.venv/bin/python` и нажмите Run в `run_local.py` без параметров. Остановка — Stop или Ctrl+C.

По умолчанию используется локальная SQLite; поддерживается локальный PostgreSQL через `DATABASE_URL`. Переменные из `.env` автоматически не читаются. Инструкция и смена занятого порта — [docs/LOCAL_RUN.md](docs/LOCAL_RUN.md).

```sh
.venv/bin/python run_local.py --check
.venv/bin/python main.py test
.venv/bin/python main.py createsuperuser
```

Последняя команда создаёт административный аккаунт с интерактивным вводом пароля. Прогресс и незавершённые проверки — [docs/PROGRESS.md](docs/PROGRESS.md).

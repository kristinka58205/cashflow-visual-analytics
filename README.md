# Поток — визуальная аналитика денежных потоков

Тема: «Разработка веб-приложения визуальной аналитики для управления денежными потоками коммерческого предприятия».
Автор: Жукова Кристина Дмитриевна (`kristinka58205`).

## Локальный запуск

Python 3.12+, Django. Виртуальное окружение и база не хранятся в Git.

```sh
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python main.py migrate
python main.py
```

Приложение: http://127.0.0.1:8021. Создайте собственный локальный аккаунт.
Проверки: `python main.py test`. Для PostgreSQL укажите переменную окружения `DATABASE_URL` и выполните миграции. Состав переменных описан в `.env.example`; автоматическое чтение `.env` пока не подключено.

Реализация развивается поэтапно; требования и фактический прогресс находятся в `docs/`.

Сейчас доступны личные счета и статьи, фактические поступления/расходы, журнал с пагинацией и обзор текущего месяца с точными денежными суммами. Изменение направления статьи с уже проведёнными операциями и удаление используемого справочника блокируются. Работают роли, импорт, бюджеты, аналитика, приватные документы операций, публичное руководство и административные сценарии. Формируемый финансовый отчёт ещё дорабатывается.

Аналитика доступна в `/analytics/`: период до 367 дней, месячные поступления/расходы, остатки и статьи. Журнал поддерживает поиск и фильтры, операции — необязательные ссылки на собственных контрагентов и проекты. Все текущие суммы в рублях.

Командный учёт: `/organizations/` — организация, реквизиты, одноразовые приглашения на сутки и роли. Рабочая область переключается явно; прежние личные записи остаются личными. Администратор и финансовый специалист изменяют учёт, руководитель просматривает данные и выгрузки. Создатель финансовой записи сохраняется при работе коллег.

Журнал `/history/` фиксирует последующие финансовые изменения в той же транзакции, предлагает фильтры и CSV. Действия до подключения журнала не добавляются задним числом.

## Запуск из IDE

Выберите интерпретатор `.venv/bin/python`, откройте `run_local.py` и нажмите Run без параметров. Адрес: http://127.0.0.1:8021 . Подготовка и проверка: `python run_local.py --check`. Пошаговая инструкция — [docs/LOCAL_RUN.md](docs/LOCAL_RUN.md).
